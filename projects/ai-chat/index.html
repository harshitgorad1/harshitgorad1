API Documentation

RESTful + WebSocket · Base URL: https://api.neurochat.ai/v1

🔐 Authentication
POST/auth/register
Register new user · Returns JWT access + refresh tokens
POST/auth/login
Authenticate user · Returns JWT pair · Sets Redis session
POST/auth/refresh
Refresh access token · Validates refresh token from Redis
💬 Chat
POST/chat/message
Send message · AI processes via Python service · Returns response + sentiment + tokens
GET/chat/conversations
List all conversations for authenticated user
GET/chat/messages/:convId
Get messages for a conversation · Paginated · Sorted by createdAt
DEL/chat/:convId
Delete conversation + all messages · Clears Redis context
WSws://api/chat/stream
WebSocket streaming · Token-by-token response · Real-time delivery
📊 Analytics
GET/analytics/user
User's personal usage stats · Token consumption · Message history
GET/analytics/admin
Platform-wide metrics · Admin only · Cached in Redis
GET/analytics/sentiment
Sentiment trend analysis · NLP derived · Last 30 days
⚙️ Admin
GET/admin/users
List all users · Paginated · Filter by plan/role
PATCH/admin/subscription
Upgrade/downgrade user subscription plan
GET/admin/system-metrics
CPU · Memory · Uptime · Error rates · Prometheus-compatible
